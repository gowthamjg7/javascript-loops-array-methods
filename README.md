# JavaScript Loops & Array Methods

A hands-on JavaScript practice assignment focused on understanding different looping techniques, working with objects, and using essential array methods.

## 📚 Topics Covered

- `for` loop
- `forEach()`
- `for...of` loop
- `for...in` loop
- Object key-value iteration
- `map()` – Transforming array elements
- `filter()` – Filtering array elements based on conditions
- `reduce()` – Calculating a single accumulated value

## 📝 Exercises

| No. | Exercise | Concept |
|---|---|---|
| 01 | Looping Through an Array | for, forEach, for...of, for...in |
| 02 | Loop Through an Object | for...in |
| 03 | Subtract 10 from Each Number | map() |
| 04 | Filter Numbers Greater Than 10 | filter() |
| 05 | Calculate Array Sum | reduce() |

## 🎯 Learning Objectives

- Understand different ways to iterate through arrays.
- Learn how to access object keys and corresponding values.
- Understand how callback functions work with array methods.
- Practise transforming, filtering, and accumulating array data.
- Improve JavaScript problem-solving skills through practical exercises.
